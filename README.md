## Installation:

### Prerequisites
- Python 3.13+
- Poetry 1.2+

All the required packages (linters and other dependencies) and environments are described in [pyproject.toml](pyproject.toml)  

1. Clone repository:
```
git clone https://github.com/simyq/sp_bank_project
```
2. Install and activate virtual environment:
```
poetry install
poetry shell
```
3. Run main.py
```
python main.py
```

## Testing
The project is covered by a suite of automated tests to ensure the reliability and correctness of its core modules. We use pytest as the test framework and pytest-cov to measure code coverage.
Running Tests

All tests are located in the tests/ directory. To run the entire test suite, execute the following command from the project root:

```
pytest
```
